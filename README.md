# Gol de Placa ⚽

Cruzadinha de Arquitetura Computacional com tema de futebol, feita com HTML, CSS e JavaScript puros.

## Como jogar

1. Abra `index.html` no navegador.
2. Clique em uma pista horizontal ou vertical e preencha as casas com letras.
3. Clique em **Conferir respostas** para ver o placar e a situação de cada palavra.
4. Clique em **Reiniciar** para começar uma nova partida.

## Palavras e pistas

| Palavra | Pista |
|---|---|
| REGISTRADORES | Pequenas áreas internas do processador que guardam temporariamente operandos e resultados imediatos. |
| DUALCORE | Processador com dois núcleos de execução, como uma dupla em campo. |
| DATABUS | Conjunto de linhas que transporta informações entre processador, memória e periféricos. |
| CACHE | Área rápida próxima ao processador que guarda informações usadas frequentemente. |
| UC | Como árbitro, coordena a execução das instruções dentro do processador. |
| CPU | Principal componente que executa instruções e processa dados no computador. |
| FLASH | Tecnologia não volátil usada em pendrives, apagada eletricamente em blocos. |
| QUADCORE | Processador com quatro núcleos de execução, como uma linha defensiva de quatro jogadores. |
| EEPROM | Tipo de armazenamento não volátil que permite apagar e regravar bytes eletricamente. |
| ROM | Armazenamento não volátil projetado apenas para leitura durante o funcionamento normal. |
| RAM | Espaço de trabalho temporário dos aplicativos, que perde dados ao desligar. |
| ADDRESSBUS | Conjunto de linhas que indica onde uma informação deve ser lida ou gravada. |
| ULA | Setor do processador responsável por operações matemáticas e comparações lógicas. |
| MICROCONTROLADOR | Pequeno chip que reúne processamento, armazenamento interno e interfaces para comandar dispositivos. |
| DMA | Como um passe direto, transfere dados entre periféricos e memória sem intervenção contínua do processador. |
| MEMORIADEMASSA | Armazenamento de longo prazo para arquivos, como vídeos das partidas, usando HD ou SSD. |

## Arquivos

- `index.html`: estrutura da página.
- `style.css`: identidade visual e adaptação das telas.
- `script.js`: dados das palavras, tabuleiro e regras do jogo.

## Site publicado

Link: a preencher após a publicação no GitHub Pages.

Crie o repositório público `arqcomp-cruzadinha` e use Settings → Pages → Deploy from a branch → main → / (root). Atualize este README com o link real e teste-o em uma janela anônima. A atividade pede pelo menos seis commits reais de desenvolvimento distribuídos em dois ou mais dias. Revise e adapte as pistas com suas próprias palavras e com o e-book da disciplina.
